github-readme-stats

Renders GitHub stats, top languages and pinned-repo cards as SVG, for embedding in a README.

Parameters

username
GitHub username. Required.
show_icons
true to show the row icons.
theme
Theme name, e.g. dark.
hide_border
true to drop the card border.
hide
Comma-separated stats to omit.
/api/top-langs/
Separate endpoint for the languages card.
Self-hosted instance, restricted to whitelisted usernames. Source and full options on GitHub.

Not on the list? Deploy your own from the repo - it is MIT licensed.
